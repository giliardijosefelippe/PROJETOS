| Token sugerido | Uso | Valor aproximado |
|---|---|---|
| `--color-brand` | Vermelho institucional | `#E00024` (validar depois contra arquivo original da marca) |

| `--color-muted` | Cinza claro / fundo | `#F5F5F5` |

Criar **tokens CSS editáveis** para todas as cores, tipografia, espaçamentos e estados.
